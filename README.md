# KorvaLabs

Official website for **KorvaLabs** — a premium product engineering and digital product studio.

## Stack

Next.js 16 · React 19 · Tailwind CSS 4 · Framer Motion · React Three Fiber

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run lint
npm run build
npm start
```

Set `NEXT_PUBLIC_SITE_URL` for canonical URLs and sitemap (defaults to `https://korvalabs.dev`).
