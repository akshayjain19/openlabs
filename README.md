# OpenLabs

Official website for [OpenLabs](https://openlabs.dev) — a product engineering studio building web products, mobile apps, AI systems, and automation for startups and SMBs.

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Framer Motion
- Three.js / React Three Fiber

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run lint
npm run build
npm start
```

Optional: set `NEXT_PUBLIC_SITE_URL` for canonical URLs, sitemap, and Open Graph.
